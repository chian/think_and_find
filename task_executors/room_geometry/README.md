# Room Geometry

## Calculation

Normalize the basic physical dimensions reported for an outbreak venue into
the room-scale quantities required by the airborne transmission calculations.

## Inputs

- `floor_area_m2`: horizontal floor area in square meters.
- `room_height_m`: mean room height in meters.
- `room_volume_m3`: room volume in cubic meters.

## Outputs

- `room_height`: effective height in meters.
- `room_volume`: room volume in cubic meters.
