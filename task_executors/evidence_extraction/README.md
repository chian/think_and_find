# Evidence extraction adapter

This directory supplies model transports and extraction contracts used by
selected reading actions. The owning episode supplies its specific information
question, actual source text and requested fields. Returned claims retain source
references, quotations, raw values and normalized units where applicable.

Extraction and provenance validation establish what was supplied and recorded.
The owning episode interprets the result within its assignment and chooses its
next work. Numerical contribution and continuation belong to the episode's
bound projection and controller.

Adapter output is a tool result. It supplies neither an independent decision
loop nor a scientific-completion verdict. Inspect concrete transport and
extraction contracts when changing a call; the inherited domain fields are not
a universal causal-research result form.
