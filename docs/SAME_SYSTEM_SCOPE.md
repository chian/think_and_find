# Same-system scope for a causal reversal

For one proposed reversal, both causal frames must concern the same focal
organism or stable interacting biological system. The comparison may change
grain, question, categories, and relations within that system. A change of
organism, host species, strain composition, or study population is an ordinary
context variable; it cannot be the evidence that the causal translation
reverses. Different organisms can still supply separate inquiries in a
collection. Comparing those inquiries may suggest an abstract pattern, but
their organism difference cannot substitute for a reversal within either one.

## Why the earlier workflow hopped between organisms

The general-search prompt explicitly invited a new biological system, and
cross-case theory requested evidence in another system. The identity resolver
allowed cases across species to share a conceptual theme. That identity rule
prevents source mixing but does not make a cross-organism contrast a valid
reversal. The case credit vector had no organism-comparability coordinate;
each new conceptual theme could add attainment, and new cross-case theory
could earn separate credit. A prompt change alone would leave that reward
path open.

## Enforced rule in v11.8

Each reviewed argument now records `shared_system`: the focal system, organism
names for both frames, the reason they overlap, exact source references, and
`same`, `different`, or `unresolved` status. Structural validation requires
those fields. Case argument progress is zero unless status is `same`, the
normalized organism sets match, and at least one cited claim bears on system
identity. An independent continuous `same_system_warrant` rating scales
otherwise valid progress; zero warrant yields zero credit. This affects the
whole case volume, including partial local credit, rather than only the final
witness term. Cross-organism cases remain visible as negative or unresolved
research records. Cross-case theory selects reviewed cases only when they have
a same-system match, and its rubric treats an organism switch as zero
nontransportability. Search, reading, synthesis, review, and theory prompts
all receive the same-system instruction.

The check is source-linked but not an independent taxonomy resolver. A model
could still misidentify an organism in the source or use the same broad name
for genuinely different study populations. A stronger enforcement layer would
extract canonical taxon and study-system identities into source records and
verify the organisms of the cited conclusion paths against those identities.
If the intended rule is one organism for the entire *collection*, the task
must additionally fix or select that organism at registration and constrain
all searches and source acquisition to it; the per-reversal rule does not do
that.
