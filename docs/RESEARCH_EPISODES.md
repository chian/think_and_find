# Episode ownership

Root coordinates sibling Discovery and Scientific jobs. Every episode iterates
through the common Episode machinery; only Root uses value of computation.

```text
Root [VOC]
├── Discovery [regular, request fulfillment]
│   └── Search
│       └── Page
│           ├── Table
│           ├── Report → Extraction Repair
│           └── Lexical Probe → Extraction Repair
└── Scientific [regular, scientific progress]
    ├── Theory Reconstruction → Theory Format Repair
    ├── Theory Repair → Theory Format Repair
    └── Theory Comparison
```

Root selects either arm using actual returns and pending scientific information
needs. There is no mandatory acquisition/assessment sequence. Discovery's query
planning replaces the former separate Search Strategy episode. Scientific's
three concrete children replace generic Reasoning and search-enabled gap work.
Each owns its decisions, complete instructions, local credit and return contract.

## Scientific and acquisition communication

Scientific records a `discovery_goal`: its question, exact scientific input
versions, requested answer JSON Schema (including custom local types), and named
executable criteria. Root forwards that exact goal to Discovery. Discovery
chooses queries, Search chooses sources, Page chooses reading, and processing
readers return source-anchored claims and observations. Their local extraction
credit is separate from discovery fulfillment and scientific merit.

A `discovery_finding` identifies its goal/version, typed answer, exact native
claim/observation selectors and scientific links. Host-generated `discovery_check`
receipts retain the checked operands and criterion results. Criteria can inspect
source-claim types, measured source values, a specified Lean equivalence request,
executed G dependence, or a linked comparison distinguishing theories.
Unresolved scientific interpretation returns through Root to Scientific. Merely
finding a name never certifies meaningful dependence on G.

Scientific can reconstruct the candidate, execute the relevant comparison and
link its scientific result to the original finding. Rechecking retains a new
receipt; credit does not rely on a model-issued pass/fail judgment. Duplicate
findings, criterion aliases and repeated formal results do not mint credit.
Discovery's local yield measures fulfillment of the commissioned criteria;
Root's shared stock also records verified new information and scientific findings.
Children's internal actions and scores are not summed into parent observations.

## Scientific children and tools

Reconstruction converts supplied source excerpts into theories, quantities, Gs,
assumptions, mechanisms and expected generalizability bounds. Repair develops and
examines concrete modifications, including G-preserving repairs. Comparison maps
accounts and evaluates failures, consequences and useful G alterations while
preserving native questions, quantities and conditions. Scientific chooses among
those jobs and issues pointed additional information goals.

Scientific and all three children can select `scientific_tool`:

* `lookup` selects existing scientific records and exact historical versions.
  It is not a hidden literature-search loop.
* `lean_equivalence` receives source-bound formal parameters/assumptions, two
  assertions, equality or logical equivalence, and proposed proof tactics. The
  adapter constructs the exact theorem, invokes the actual Lean kernel and
  retains its result and axiom report. Failure to check equivalence is unresolved,
  not evidence of inequivalence. Lean need not be used for every assertion.
* `causal_calculation` executes an admitted SCM/equation/simulation protocol and
  requested circumstances, retaining reproducible importance-result receipts.
  The present evaluator supports deterministic acyclic SCMs and explicit discrete
  dynamics. Unsupported feedback/implicit dynamics remain explicit rather than
  being silently flattened into a different model.
* `compare_tasks` executes a declared `causal_change` task comparison against
  its original/reference models. Explicit equations and ODE directional-event
  times produce reproducible results, numerical refinement estimates and gradual
  error-improvement credit. Original expected bounds, successful tasks, losses
  and nonrepresented events remain explicit. Extensions outside original bounds
  are not excluded and original-G support cannot zero this contribution.

Each tool returns a `tool_receipt` naming its exact scientific input versions,
request, actual result, artifacts and limitations. The invoking episode receives
that result in its next decision and can revise its formalization, repair or
comparison. Tool use is not an additional episode or compulsory sequence.

A source-grounded `examination` registers G's first public assessment using its
exact G/theory snapshots, a reasoning argument and source-linked premises.
One progress point is deduplicated per canonical G; supported, challenged and
unresolved conclusions can all be examinations. That registration does not
establish support, causal change or scientific truth. Support and graduated
task-comparison calculations retain their own operands and scientific limits.

## Retained transport and continuation

Every decision receives its own assessment, selected records and newly returned
information. Returns retain final unreviewed outcomes even if the controller
immediately yields. Full public records remain addressable by key/version;
parents' private histories and recursive traces are not child input. There is
no report-composition episode.

All children use the existing ordinary numerical yield estimator. Root alone
uses VOC observations of completed commissions and own actions. Unknown
forecasts remain unknown; no episode elapsed-time, token, turn, action or
cumulative-usage budget is introduced. CPU/RAM constraints belong to the whole
execution environment, separately from research continuation.
