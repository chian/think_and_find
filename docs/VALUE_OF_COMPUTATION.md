# Root value of computation

Only `RootSource` uses `RootVOCController`. Discovery, Scientific, Reconstruction,
Repair, Comparison and acquisition readers use the common regular yield estimator.
Root chooses between sibling Discovery and Scientific commissions, explicit new
information goals and read-only recall. It does not prescribe a child itinerary.

## Observations and credit

The stock is the exact sum of explicit investigation components: G registration,
expected generalizability bounds registration, theory/context applications, first
source-grounded G examinations, verified discovery progress, support and useful
causal change. These components retain separate meanings and identities.

One completed Root own action or child commission creates one signed score-change
observation. A child's internal turns do not become Root turns and child scores
are not added. Shared refresh exposes records and stock without inventing an
observation or erasing the parent's frozen pre-action baseline. Scientific work
can resolve a pending discovery criterion; the retained check and its actual
credit enter that completed scientific outcome once.

A first examination is a source-linked public assessment of a defined G using
specified theories and reasoning. Its registration measures progress, not truth.
A tool invocation, episode visit or arbitrary pass verdict does not earn it.
Support and useful-change points still require their separate scientific operands.

## Forecasts and continuation

The reusable Bayesian VOC algorithm knows no scientific tasks. The Root binding
uses actual signed transitions over available actions and shared scientific state.
Exact-state observations take precedence; otherwise observed transitions are
pooled by Root action set, scientific record kinds/currentness, selected input
kinds, represented component kinds, checked results and score-component features.
This structural exchangeability is a forecasting approximation, not scientific
equivalence between candidate contents.

Each Root decision receives immediate, continuation and total expected gains,
predictive dispersion, improvement probability, evidence IDs and unmodeled
choices. Zero-credit preparation can lead to a later valuable assessment when
completed trajectories supply that evidence. Unknown forecasts remain unknown;
they are not zero or invented priors. Model state starts fresh in a new normal
run; prior scientific state is not silently resumed.

Forecast depth describes hypothetical calculation, never a limit on actual
execution. Root's default zero yield threshold keeps the standing investigation
open. At a nonzero configured threshold the existing VOC rule requires all
examined choices to be modeled and no profitable continuation. Cold-start or
unmodeled choices may therefore keep it open; this is not proof of scientific
completion and introduces no wall-time, token, turn or action budget.

## Focused validation

`scripts/verify_episode_organization.py` exercises actual routing, controller
ownership, scientific tool action contracts, request/result handoffs and credit
identities. `scripts/verify_scientific_tools.py` invokes the real Lean kernel and
SCM evaluator. `scripts/verify_failed_yield.py` checks failed child outcomes and
natural yield. These are targeted implementation checks; scripted fixture choices
do not establish autonomous scientific behavior. A fresh normal workflow is
required to inspect that behavior.
